### Generate step (batches, folders, resume)

- **Files:** `src/lib/generate/{plan,items,surface,pdf,job}.ts` (pure planning, work list, hidden-frame renderer, pdf-lib helpers, job state + sinks) and `src/steps/generate/{gen.svelte.ts,GenerateStep,SummaryBar,ChecksPanel,ProgressPanel,OptionsPanel,PlanPanel,PreviewPanel,ResultsPanel}.svelte`. Flow has NO generate button/progress; the Generate tab only.
- **Work list:** `buildItems(flowUi.result, ws.sheetOf, settings)` -> `GenItem{key,list,row,design,id,group[]}`; `key = list::id` (id = value of the id column, or `row-N`). Id column per data list: chosen or auto (`guessIdColumn`: all-unique, id-like name first). Group column per list: none / auto (`guessGroupColumn`: a few repeated values, team/class-like names win; with 2+ lists a folder per data file first) / custom.
- **Batches:** `planBatches` (default size 50, buffer 10, keep groups): small groups packed to the size, a group up to size+buffer stays whole, bigger groups cut into chunks of size with the last chunk taking the rest (105 = 50+55, 112 = 50+50+12). `settings.moves` = groups moved by hand in the Batch plan panel (cleared whenever batching/grouping options change). Path pattern default `batch-{batch}/{group}/{id}.pdf` (one PDF per student) or `batch-{batch}/{group}/{design}.pdf` (combined: one PDF per batch, group and design). Duplicate paths block Generate.
- **Run:** `gen` store. `#run` goes batch by batch, certificate by certificate, yields to the browser between certificates, saves the job (IndexedDB `generate-job`, and `config/generate.stat.json` in the linked folder at batch end / stop / finish). Stop = finish the current certificate; Continue resumes at `batch.done`; combined mode keeps each page in IndexedDB (`genpage:`) until the batch is complete, then merges per path. `fingerprint` (data, designs, flow items) -> "stale" banner. Clear progress / Clear and delete files. Failed items are listed with "Try them again". Wake lock + beforeunload guard while running. Preview 10 = random items (>=1 per design) rendered in memory, nothing saved.
- **Renderer (current = image mode):** `DesignSurface` loads a design ONCE in a hidden frame (fields left as written), `setRow` swaps only the field text, `toJpeg` uses html2canvas (quality 1/2/3 = scale), `pdfFromJpeg` wraps it in a page sized like the design. ~135 KB per certificate at standard quality. **NOT built yet: the vector PDF writer** (real text/shapes with embedded fonts, image fallback only for effect-heavy designs), which was the agreed goal for sharper, selectable, smaller PDFs.
- **Output goes to `output/` of the linked workspace folder** (`folderSink`); browsers without folder access get a zip per finished batch (`zipSink`, a half batch restarts on Continue). If the workspace is not linked, Generate first asks for a folder (`saveWorkspace`).
- **Workspace folder link (fixed this session):** `lib/workspace/folder.ts` (handle in IndexedDB, `FolderSync` writes only changed files, never deletes files it did not write). `ws.linkFolder / reconnectFolder / unlinkFolder / syncFolder`, `ws.folderState` (none | linked | needs-permission); the store schedules a folder write 700 ms after each change; opening a folder links it (files already there are not rewritten). Workspace menu shows the link state; header status reads "In folder". Data files are saved as `<their own name>.csv`. Verified headless with an OPFS stub (`showDirectoryPicker` -> `navigator.storage.getDirectory()` + permission stubs); the real picker could not be driven by automation.

### Later changes (same session)

- **Data files keep their own names:** nothing is renamed to data.csv any more. - **Flow condition node:** `match: 'each'` (default for new nodes) = one yes output PER condition row (ports `true` = row 1, `y1`, `y2`…) plus `false` = else; evaluated top to bottom, first hit wins. `all`/`any` = legacy single yes (used by the simple form). `ops.portsOf/yesPort/removeClause` handle ports; removing a row shifts later connections up. One-line rows (`ClauseRow compact`), list scrolls after 3 rows (handles sit inside the scroller at right:8px), `useUpdateNodeInternals` after row count changes. Simple form returns null for an `each` node with 2+ rows.
- **Switching Data node finds the same PERSON in the other list** (e.g. Roll Number 2023507030 in data.csv -> their row in the grades xlsx): `ws.makeRemap()` (exact via `combined.origins` between the merged table and its own file, otherwise a key match with `matchColumns(a,b)` = same-named column, id-like and all-different preferred; user can pick `matchFrom`/`matchTo` on the Data node; cached lookups, `normKey` ignores case/spaces/leading zeros).
