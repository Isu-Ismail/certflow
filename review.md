# CertFlow review (branch `redesign`) — all P0-P2 items and UX items U1, U7 and #12 fixed since; see .knowledge/session_handoff.md

Reviewer: grumpy old manager. Verdict: **NOT approved.** The feature set is wide, but a production-grade product is more than a wide feature set. Read the table, fix the P0 items first, then come back.

Scope reviewed: `index.html`, `App.svelte`, `render/compile.ts`, `generate/{surface,plan,job}.ts`, `workspace/{store,persist,tokens,actions}`, `design.svelte.ts`, `visual/ops.ts`, `package.json`, `.knowledge/session_handoff.md`. I read code and the handoff notes. I did not run every flow in a browser, so items marked "verify" need a reproduction.

## Bugs and risks

| # | Sev | Where | Problem | Why it happens | Fix |
|---|-----|-------|---------|----------------|-----|
| 1 | P0 | `actions.ts:130` `saveNow()` / `store.svelte.ts:116` `flush(true)` | **Ctrl+S before the autosave has loaded overwrites the saved workspace with an empty one.** The stage is blank while `ws.ready` is false, but the global keydown handler is already active. | `flush(force=true)` skips the `#dirty` check and has no `ready` guard. `restore()` is async, so `meta` is built from the empty initial state. | Return early in `flush` while `!this.ready`. Make `saveNow` await a `ws.whenReady` promise. Never write a force-save from an unloaded store. |
| 2 | P0 | `surface.ts:38`, `design.svelte.ts` trust, `PagePreview` iframe | **`allow-scripts` + `allow-same-origin` together is not a sandbox.** A trusted design script can remove its own `sandbox` attribute, read the parent's IndexedDB (all workspaces, all data rows) and `localStorage`. The same iframe flags are used for hidden generation. | Both flags on a same-origin `srcdoc` give the frame the full origin. | Never combine the two. If scripts are needed, use `allow-scripts` only, so the frame gets an opaque origin, and send blob URLs in as data. Better: drop script support (the handoff already says "designs should not need JavaScript"). |
| 3 | P0 | `design.svelte.ts:#trustId` | **Script trust is keyed by `workspaceName::designName`.** Open or import another workspace with the same names (`Untitled::Design 1` is the default) and its scripts are already trusted, with no prompt. | The key uses user-editable names, not the design content. | Key trust by a SHA-256 of the design HTML. Any edit or replacement revokes trust. |
| 4 | P1 | `plan.ts:210` path building | **`..` segments survive in the output path.** The pattern is only split, filtered for empty segments and stripped of `\:*?"<>\|`. A pattern like `../{id}` or a `..` segment from a typed pattern goes straight to the sink. | Segments are not checked against `.` and `..`. | Drop or replace any segment that is `.` or `..`. Reject patterns that contain them in the validator, and show the error in the Checks panel. This also stops zip-slip in `zipSink`. |
| 5 | P1 | `package.json` `xlsx@0.18.5` | **Known CVEs (prototype pollution, ReDoS) on a library that parses files from strangers.** The handoff admits this and defers it. | npm only has 0.18.5 on the registry. The fix versions are on the SheetJS CDN. | Install from the SheetJS CDN tarball, or move to `exceljs` or `read-excel-file`. Cap file size and row count before parsing. |
| 6 | P1 | `index.html:7` CSP | **The CSP does nothing.** `default-src ... 'unsafe-inline' 'unsafe-eval' https:` allows every script and any https origin. It is a `<meta>` CSP, so it cannot set `frame-ancestors`. | The policy was written to avoid breaking things, not to block them. | Remove `unsafe-eval` (test whether anything needs it), restrict `connect-src`, `font-src`, `style-src` to named hosts, and add `frame-src blob: data:`. Move the CSP to the host's response headers. |
| 7 | P1 | `store.svelte.ts:restore()` | `ready = true` is set before `await loadXlsx()` and `#restoreFolder()`. The user can edit, and an autosave or a folder sync can fire while the Excel writer is not loaded or the folder permission is unresolved. Saving an `xlsx` sheet needs the lazy lib. | Readiness is one boolean for three async stages. | Finish all stages first, or make `ready` the last line. Show a real loading state instead of a blank `<main>`. |
| 8 | P1 | `persist.ts`, no `BroadcastChannel` or `navigator.locks` | **Two tabs of the app overwrite each other.** The last `saveAll` wins and the other tab's data is lost, with no warning. `db.onversionchange` closes the DB but nothing tells the user. | One IndexedDB record is rewritten whole by whichever tab saves last. | Take a Web Lock per workspace, or broadcast "another tab is open" and make the second tab read-only. |
| 9 | P1 | `index.html:8-10` | **Render-blocking Google Fonts stylesheet.** A tool that says "works offline" fails its first paint when the font host is slow or blocked, and sends the visitor's IP to Google. | External CSS in `<head>` without `media`/`display` tricks. | Self-host the two fonts (woff2, `font-display: swap`) and preload the one used above the fold. |
| 10 | P1 | `dist/assets/index-*.js` 1.3 MB (no gzip size known) | **One 1.3 MB main chunk.** Svelte Flow, pdf-lib, jsPDF (legacy), lucide x2 and CodeMirror glue sit in or near the entry. First load on a phone network is slow. | Only `xlsx`, `jszip`, the graph editor and CodeMirror are lazy. | Add `build.rollupOptions.output.manualChunks`, lazy-load `pdf-lib` and `modern-screenshot` at first Generate, delete `jspdf` and `lucide-svelte` (two icon libraries for one set of icons). Check with `rollup-plugin-visualizer`. |
| 11 | P2 | `index.html` | **SEO and share basics are missing.** No `<meta name="description">`, no canonical, no Open Graph or Twitter card, no `robots.txt`, no `sitemap.xml`, no structured data, `<div id="app">` is empty with no `<noscript>`. The page is `/certflow/` under a sub-path, so the favicon and OG image need absolute URLs. | Boilerplate was never replaced. | Use the `search-engine-optimization` skill. Add description, canonical, OG image (1200x630), `robots.txt`, `sitemap.xml`, `SoftwareApplication` JSON-LD, and a static `<h1>` and a short text block inside `#app` for crawlers and no-JS users. |
| 12 | P2 | `App.svelte:41` | `Ctrl+S` calls `preventDefault()` and saves to IndexedDB. A user who wants a real file gets a toast that says "Saved in this browser" and nothing on disk. | Overloaded shortcut. | Keep it, but when the workspace is not linked to a folder, say so in the toast and offer "Save to folder". |
| 13 | P2 | `App.svelte:38-46` | The undo/redo handler casts `e.target as HTMLElement` and calls `.closest`. Keydown fired from `document` or an iframe element that is not an `Element` can throw. Focus inside the preview iframe also swallows Ctrl+Z. | Unchecked cast. | `const t = e.target instanceof Element ? e.target : null`. |
| 14 | P2 | `visual/ops.ts:158` | `t.innerHTML = \`${t.innerHTML} ${text}\`` re-parses the whole element to append a token. It destroys the browser's text selection and any child element identity, and is one escape bug away from HTML injection. The token regex blocks `<>` today, which is why it is safe today. | String concatenation on HTML. | Append with `t.append(' ', document.createTextNode(text))`. |
| 15 | P2 | `surface.ts:61` `#settle()` | `img.onload`/`onerror` has no timeout. A blob that never resolves (revoked URL, huge image) hangs the whole run on the first certificate. | No deadline on the wait. | `Promise.race` against a 10 s timer, and report the broken image in Checks. |
| 16 | P2 | `surface.ts:150-190` `textRuns()` | Per-character `Range.getClientRects()` for every text node, for every certificate, is O(characters) layout reads. Slow on a 1,000-row batch, and Indic or Arabic text is silently left unselectable. | Layout is read in a loop. | Cache the run geometry per design, and only swap the string for each row. Warn in the UI when characters are skipped. |
| 17 | P2 | `package.json` | `lucide-svelte` and `@lucide/svelte` are both installed. `jspdf`, `html2canvas`, `xlsx`, legacy `src/lib/utils/*` and `src/lib/types.ts` are old code still in the tree. Two screenshot libraries plus jsPDF plus pdf-lib. | The redesign never finished cleanup. | Delete the legacy code in the same PR as the redesign. One icon library, one PDF library. |
| 18 | P2 | Repo state | **The whole redesign is uncommitted** (dozens of deletions and `??` folders) with no tests and no linter. One bad `git checkout` loses weeks. | Work was never committed to the `redesign` branch. | Commit now, in small steps. Add `vitest` for `flow/evaluate`, `plan.ts`, `combine.ts`, `tokens.ts`. Add `svelte-check` to a CI step. |
| 19 | P2 | `README.md` / `.knowledge/*` | The docs still describe the OLD app. A new agent is told to trust a file that is wrong. | Docs deferred. | Rewrite after the commit. |
| 20 | P3 | `index.html` | No `theme-color`, no manifest, `lang` only. No error boundary: a thrown error in a step leaves a white `<main>`. | Not considered. | Add `window.onerror` and `unhandledrejection` handlers that show a recovery message with "Download my workspace". |

## UX and usability friction (I used it like a real user)

| # | Where | Friction | Fix |
|---|-------|----------|-----|
| U1 | First load | Blank rectangle while IndexedDB loads (`{#if !ws.ready}` is an empty comment). A returning user thinks the data is gone. | Skeleton or spinner with "Opening your workspace...". |
| U2 | Whole app | Four steps in one header row, workspace menu, undo, redo, save, help, status. On a phone this wraps to a second row and the stage shrinks. The `h-dvh` shell leaves little height once the keyboard opens. | Collapse secondary actions into one overflow menu below 640 px. Test with the on-screen keyboard open. |
| U3 | Handoff notes | The Design editor has hidden gestures (Space+drag to pan, Ctrl+wheel to zoom, double-click to drill into groups, Shift+arrow = 10 px). A user report said "cannot move or edit blocks, only the cursor shows". It was not reproduced, and the likely cause was lost focus. | Show a small "Tips" strip on first visit, and a visible hand/zoom control. Fix the cause (focus), not just the symptom. |
| U4 | Generate | Many options (renderer, quality, selectable text, batch size, buffer, groups, path pattern). A first-time user must understand "buffer 10" before pressing Generate. | One big "Generate with recommended settings" button; put everything else under "Advanced". |
| U5 | Generate output | Browsers without folder access get a zip per finished batch with no explanation of why. Safari and Firefox users hit this first. | Explain at the top of the page which browser mode is in use and what will happen. |
| U6 | Destructive actions | Remove data, delete design and delete files ask for confirmation, but undo is memory-only (100 steps, cleared on reload). A reload makes the "undo" promise false. | Say "Undo works until you reload" in the confirm text, or persist the history. |
| U7 | Accessibility | 91 `aria-label`s but click handlers on `<div>`/`<span>`, hover-only checkboxes in the Files list, and a "!" hint (`InfoTip`) that needs hover or click. Keyboard and touch users miss them. Contrast of the `bg-step` colours on `text-on-step` is not checked. | Use real `<button>`s, show checkboxes on focus, run axe or Lighthouse a11y, and check 4.5:1 contrast for each step colour. |
| U8 | Error recovery | Folder rules are strict: a folder without a valid mark is refused, and a linked folder must be empty. A user with an existing folder of certificates has no import path. | Add "Import into a new workspace" that copies from a chosen folder. |
